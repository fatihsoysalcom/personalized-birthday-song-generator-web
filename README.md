# Personalized Birthday Song Generator Web

This example demonstrates a simple web-based personalized birthday song generator. It takes a name as input and plays a classic 'Happy Birthday' melody, displaying personalized lyrics in the browser. The audio is generated dynamically using the Web Audio API, illustrating how to create basic musical tones.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a modern web browser.
3. Enter a name in the input field and click 'Şarkıyı Oluştur ve Çal' (Generate and Play Song).
